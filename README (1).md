# DisasterSense Rev-B Manufacturing Package

Board: 100 mm x 70 mm, 2-layer, 1.6 mm nominal FR-4 carrier/hub.

Manufacturing outputs:
- F_Cu / B_Cu
- F_Mask / B_Mask
- F_Silkscreen / B_Silkscreen
- Edge_Cuts
- Excellon PTH drill file

The design is a modular sensor-hub carrier for an ESP32-S3 DevKitC-1-class board. External sensors use headers. Confirm the exact DevKitC-1 revision and connector orientation before assembly.

Before placing a paid PCB order, load all Gerbers and the DRL into JLCPCB's viewer and confirm board outline, hole count, layer alignment and connector orientation.
